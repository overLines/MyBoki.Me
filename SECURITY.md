# 🔐 Security Policy / Sicherheitsrichtlinie

Security is important to us. Thank you for helping us keep MyBoki.me and
its users safe.

Sicherheit ist uns wichtig. Vielen Dank, dass du dabei hilfst, MyBoki.me
und seine Nutzer zu schützen.

---

## 🇩🇪 Sicherheitslücke melden

Wenn du eine mögliche Sicherheitslücke in MyBoki.me gefunden hast,
**erstelle bitte kein öffentliches GitHub Issue dafür.**

Dies gilt insbesondere für mögliche Sicherheitsprobleme in den Bereichen:

- Authentifizierung und Benutzerkonten
- Zugriff auf fremde Daten
- Datenschutz oder Offenlegung personenbezogener Daten
- Berechtigungen und Zugriffskontrollen
- APIs und Backend-Endpunkte
- Sessions, Tokens oder Zugangsdaten
- Möglichkeiten zur Umgehung von Sicherheitsmechanismen
- andere Schwachstellen, die MyBoki.me oder seine Nutzer gefährden könnten

### Bitte nicht veröffentlichen

Veröffentliche niemals folgende Informationen in einem öffentlichen Issue:

- Passwörter
- API-Keys oder Tokens
- Zugangsdaten
- personenbezogene Daten
- Session-Informationen
- private URLs oder interne Systeminformationen
- Informationen, mit denen eine Sicherheitslücke unmittelbar ausgenutzt
  werden könnte

### Wie melde ich eine Sicherheitslücke?

Bitte melde Sicherheitsprobleme vertraulich über:

**E-Mail:** security@myboki.me

Bitte beschreibe möglichst:

1. Welche Sicherheitslücke du gefunden hast
2. Welcher Bereich von MyBoki.me betroffen ist
3. Wie sich das Problem reproduzieren lässt
4. Welche möglichen Auswirkungen du festgestellt hast
5. Falls hilfreich: Screenshots oder weitere technische Informationen

Bitte veröffentliche Details zur Sicherheitslücke nicht öffentlich,
solange das Problem nicht untersucht und behoben wurde.

Normale Fehler und Verbesserungsvorschläge können weiterhin über die
GitHub Bug- und Feature-Request-Formulare gemeldet werden.

---

## 🇬🇧 Reporting a Security Vulnerability

If you discover a potential security vulnerability in MyBoki.me,
**please do not create a public GitHub issue.**

This particularly applies to potential security issues involving:

- Authentication and user accounts
- Unauthorized access to user data
- Privacy or exposure of personal data
- Permissions and access controls
- APIs and backend endpoints
- Sessions, tokens or credentials
- Bypassing security mechanisms
- Other vulnerabilities that could affect MyBoki.me or its users

### Do not publish

Never include the following information in a public issue:

- Passwords
- API keys or tokens
- Credentials
- Personal data
- Session information
- Private URLs or internal system information
- Information that could directly enable exploitation of a vulnerability

### How to report a vulnerability

Please report security vulnerabilities privately via:

**Email:** security@myboki.me

Please include, where possible:

1. A description of the vulnerability
2. The affected area of MyBoki.me
3. Steps to reproduce the issue
4. The potential impact
5. Screenshots or additional technical information, if helpful

Please do not publicly disclose details of the vulnerability while the
issue is being investigated and resolved.

Regular bugs and feature requests can continue to be submitted using
our GitHub Bug Report and Feature Request forms.

---

## Responsible Disclosure

We appreciate responsible reports that help us improve the security of
MyBoki.me and protect our users.

Please give us reasonable time to investigate and address a reported
security vulnerability before publicly disclosing information about it.
